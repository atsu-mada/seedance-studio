Surface Prompt Profiles

Use this reference to keep platform behavior surface-specific. Do not hardcode duration, prompt length, reference counts, tag syntax, edit support, extension support, audio behavior, regions, pricing, or authorization requirements as universal Seedance facts.

Profile Fields

For the active surface, resolve:

  • exact reference-tag convention;
  • verified duration range;
  • prompt budget;
  • supported reference roles;
  • timeline syntax;
  • edit or extension availability;
  • audio behavior;
  • known constraints;
  • source and verification date.

If the surface is unknown, state that the profile is conservative and avoid unsupported numbers.

Conservative Generic Profile

Use only when no surface is known:

  • plan one compact generation-sized clip at a time;
  • keep prompt concise;
  • preserve exact user-supplied tags;
  • avoid asserting native extend, prompt limits, or reference counts;
  • ask for the actual clip or final frame before continuation;
  • prefer role-bound references over unsupported feature claims.

Seedance 2.5 Verified Profiles (2026-09-04)

ByteDance model capability: a single generation can run up to 30 seconds. This establishes the model ceiling, not the controls exposed by every host.

BytePlus enhanced video generation: 4–30 seconds for dreamina-seedance-2-5-260628 on the documented route. The page does not establish a universal 5,000-character prompt limit.

Higgsfield: up to 30 seconds is documented on Higgsfield's Seedance 2.5 model page. The public page did not state a prompt-character budget at verification time. If the user requests a 4,500–4,900-character Higgsfield prompt, treat that as an authoring target and verify the active field counter before claiming paste-ready compatibility.

Leonardo.AI: the provider documentation specifies a maximum 5,000-character prompt for bytedance/seedance-2.5. Count the submitted prompt value only, including spaces and line breaks; keep a small margin unless the user explicitly requires an exact boundary test.

For any 30-second prompt, allocate time before prose: define the opening state, timestamped turns, one motivated camera purpose per phase, continuity locks, and an explicit final state. A longer budget does not authorize extra story beats. Remove repeated quality adjectives before removing action, spatial logic, or continuity instructions.
